How it works

Three taps. No account, no setup.

1

Drop a pin

Stand at the door, open the map, and tap the exact place.

2

Write a note

Add the small directions only you know: the gate color, the floor, who to ask for.

3

Find it again

Next delivery, open the place and see the pin and your note. Mark it Done when you finish.

How to install

  1. Tap Download APK and open the file when it finishes.
  2. If Android asks, allow your browser to install apps.
  3. If Google Play Protect shows a warning, tap More details, then Install anyway.
  4. Open Medresha and tap the + button to save your first place.
Why the warning? Google shows it for any app that does not come from the Play Store. The code is open to look at on GitHub.

Questions

Does it work without internet?

Your saved places and notes open without internet. The map pictures need internet to load.

Is there an iPhone version?

Not yet. Medresha is Android only for now.

Do I need an account?

No. Open the app and start saving places.
